                  Sharing setup

                  To log results, change the ban list or update ratings, this phone needs a GitHub access token. Viewing works without one. The token is saved only on this phone.

                  Win odds start from the Elo formula, then use the calibration that has been more accurate on past matches. Form, head-to-head, and how many matches a player has already played today are added only when that has lowered the error. A saved book price is mixed in only after priced results show that the mix is closer. None of this edits the ban list. Tap a player's ban list tag to add or remove them.
